Лабораторна робота №3

Тема: Користувачі, групи, права доступу та керування процесами у ОС Linux.

Мета: Навчитися створювати користувачів різними способами, керувати групами та правами доступу, працювати з ACL, а також контролювати процеси у терміналі Linux.

Хід виконання роботи

1–5. Створення та налаштування користувачів

Створено користувачів за допомогою команд adduser та useradd. Перевірено створення домашніх каталогів, задано паролі, виконано вхід під новим користувачем та порівняно записи у файлі /etc/passwd.

6–7. Створення групи та керування членством

Створено групу laptii_labusers. До неї додано створених користувачів та перевірено їхнє членство у групі.

8–13. Права доступу та ACL

Створено каталог /laptii_labsecure з підкаталогами docs та private. Налаштовано власників, групи та стандартні права Linux.

Для каталогу docs групі laptii_labusers надано повний доступ, а каталог private спочатку доступний лише користувачу root.

За допомогою ACL користувачу laptii_useradd02 надано права r-x на каталог private. Для каталогу право x необхідне для переходу до його об'єктів, тому r-x фактично забезпечує доступ лише для читання без можливості створювати або змінювати файли.

Уточнення прав доступу до секретного файлу

Додатково права файлу laptii_secret.txt встановлено як 600, тобто читання і запис дозволені лише користувачу root. Також перевірено відмову в доступі для laptii_useradd02.

14–15. Файл /etc/shadow та журнал авторизацій

Переглянуто записи нових користувачів у файлі /etc/shadow та перевірено системний журнал на наявність записів, пов'язаних з авторизацією створених користувачів.

16–18. Основи керування процесами

Створено файл laptii_task1.txt та відкрито його у редакторі nano. Продемонстровано перегляд запущеного процесу, його призупинення та повернення на передній план.

Також команду sleep запущено у фоновому режимі, перевірено список фонових задач за допомогою jobs та повернуто процес на передній план командою fg.

19–20. Моніторинг та завершення процесів

Запущено декілька процесів та виконано їх моніторинг за допомогою команди top.

У top список процесів відсортовано за використанням оперативної пам'яті. Один із власних процесів завершено безпосередньо з інтерфейсу top, інші процеси завершено командою kill.

Коментар

Основні етапи лабораторної роботи задокументовано у вигляді записів термінальних сесій за допомогою утиліти asciinema.

Завдання логічно об'єднано у тематичні блоки: керування користувачами, групами, правами доступу, ACL, журналами авторизації та процесами.
