# Чеклист схем і діаграм для курсової роботи

**Тема:** Проєктування та програмна реалізація моделі адаптивного освітнього процесу з інтелектуальним навчальним агентом та аналізом прогресу здобувача освіти.

**Межі реалізації:** робочий POC, один основний навчальний модуль, модульний моноліт (React + TypeScript; Python + FastAPI; LangGraph за потреби; PostgreSQL + pgvector; LLM API).

**Позначення:** **P0** — обов’язково для курсової; **P1** — бажано; **P2** — можна перенести в дипломну. Пріоритет є рекомендацією, а не формальною вимогою закладу освіти.

## Рекомендований мінімум для курсової

**12 позицій P0**: контекст системи; загальна архітектура; внутрішні модулі; структура навчального модуля; цикл навчання; sequence одного кроку; перевірка розуміння; машина станів адаптації; оцінювання й педагогічне рішення; ERD; формування прогресу; матриця тестів.

> Не обов’язково робити 12 окремих рисунків: цикл навчання та оцінювання можна об’єднати; загальну архітектуру й внутрішні модулі — показати двома рівнями однієї C4-схеми. Матриця тестів оформлюється таблицею.

**Практична послідовність:** контекст → архітектура → модульні межі → структура предметного модуля → цикл/sequence → оцінювання → стани адаптації → ERD → аналітика → тести.

**Застереження:** не варто перевантажувати курсову дубльованими схемами або креслити компоненти, яких немає в реалізованому POC. Якщо певний елемент лише запланований, явно позначити його як перспективний. Тести функціональності не доводять педагогічної ефективності.
