## 1. Загальна інформація

Метою роботи на цьому етапі є знайти декілька реальних наборів погодних даних, оцінити їх придатність для подальшого аналізу та обрати один основний набір даних.

Для роботи обрано не випадкові готові CSV-файли, а дані з джерел, які використовуються для професійної роботи з метеорологічними та кліматичними даними:

- **NOAA NCEI / GHCN Daily**;
- **NASA POWER**;
- **Copernicus Climate Data Store / ERA5**.

### Об'єкт дослідження

Для порівняння джерел зафіксовано приблизно одну географічну область та однаковий часовий період:

- **локація:** Київ, Україна;
- **основні координати:** приблизно `50.4 N, 30.53 E`;
- **період:** `01.01.2020 – 31.12.2024`;
- **основна гранулярність:** щоденні дані, де це можливо.

> **Мій коментар.** Я вирішив не шукати три повністю різні набори даних про погоду. Замість цього взяв приблизно одну локацію та однаковий період, але різні джерела. Так порівняння має більше сенсу: змінюється саме джерело і спосіб отримання даних, а не одночасно країна, період і набір показників.

## 2. Ключові слова для пошуку

Для пошуку використовувалися англомовні ключові слова, оскільки більшість великих міжнародних репозитаріїв описують набори даних англійською:

- `historical weather data`;
- `daily weather dataset`;
- `daily climate observations`;
- `weather station data`;
- `temperature precipitation humidity wind dataset`;
- `historical weather observations Ukraine`;
- `daily weather data Ukraine`;
- `climate reanalysis daily data`;
- `meteorological dataset CSV`;
- `surface weather observations`.

> **Мій коментар.** Я не обмежував пошук словом `weather dataset`. Додав слова `station`, `observations`, `reanalysis`, `daily`, тому що вони допомагають знайти не просто випадкові таблиці, а зрозуміти походження даних і їхню часову структуру.

## 3. Обрані джерела для пошуку

### 3.1. NOAA NCEI — GHCN Daily

**NOAA National Centers for Environmental Information** надає глобальні архіви метеорологічних спостережень. Для роботи використано набір **GHCN Daily** та станцію:

- **назва станції:** KIEV;
- **Station ID:** `UPM00033345`;
- **координати станції:** `50.4, 30.5331`;
- **період вибірки:** 2020–2024;
- **формат:** CSV.

Посилання:  
https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily

### 3.2. NASA POWER

NASA POWER дозволяє отримувати часові ряди метеорологічних показників для заданих координат.

Для роботи сформовано вибірку:

- **координати:** `50.4, 30.5331`;
- **період:** 2020–2024;
- **крок:** 1 день;
- **формат:** CSV.

Обрані параметри:

- `T2M` — середня температура на 2 м;
- `T2M_MAX` — максимальна температура;
- `T2M_MIN` — мінімальна температура;
- `T2MDEW` — температура точки роси;
- `RH2M` — відносна вологість;
- `PRECTOTCORR` — скоригована кількість опадів;
- `WS10M` — швидкість вітру на 10 м;
- `PS` — атмосферний тиск біля поверхні.

У заголовку завантаженого файлу вказано, що ці параметри походять із **MERRA-2**.

Посилання:  
https://power.larc.nasa.gov/

### 3.3. Copernicus CDS — ERA5

Для третього кандидата використано **ERA5 hourly time-series on single levels** із Copernicus Climate Data Store.

У завантаженому файлі:

- **період:** 2020–2024;
- **крок:** 1 година;
- **формат:** CSV;
- **координати точки у файлі:** `50.25, 31.0`.

Основні параметри:

- `t2m` — температура на 2 м;
- `d2m` — температура точки роси;
- `u10`, `v10` — компоненти вітру на 10 м;
- `sp` — поверхневий тиск;
- `tp` — загальна кількість опадів;
- `valid_time` — дата і час.

Посилання:  
https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels-timeseries

> **Мій коментар.** ERA5 тут трохи відрізняється від перших двох наборів: він погодинний, а координати точки не збігаються один в один з координатами станції NOAA. Для цієї лабораторної це прийнятно, тому що зараз я порівнюю придатність наборів для подальшої роботи, а не виконую точне зіставлення значень між джерелами. Якщо в наступних роботах буде потрібне пряме порівняння джерел, координати краще буде вирівняти.

## 4. Первинна оцінка знайдених наборів

### 4.1. NOAA GHCN Daily — KIEV

Завантажений CSV містить:

- **1731 запис**;
- **155 колонок загалом**;
- **11 колонок мають дані**, решта порожні для цієї конкретної вибірки;
- період від `2020-01-01` до `2024-12-31`;
- дублікатів дат не виявлено.

Основні заповнені поля:

| Поле | Опис |
|---|---|
| `STATION` | ідентифікатор метеостанції |
| `NAME` | назва станції |
| `LATITUDE` | широта |
| `LONGITUDE` | довгота |
| `ELEVATION` | висота над рівнем моря |
| `DATE` | дата спостереження |
| `TAVG` | середня температура |
| `TMAX` | максимальна температура |
| `TMIN` | мінімальна температура |
| `PRCP` | опади |
| `SNWD` | висота снігового покриву |

Кількість наявних значень для основних погодних полів:

| Поле | Заповнених значень |
|---|---:|
| `TAVG` | 1731 |
| `TMAX` | 1416 |
| `TMIN` | 924 |
| `PRCP` | 364 |
| `SNWD` | 254 |

Кількість записів за роками:

| Рік | Кількість записів |
|---|---:|
| 2020 | 366 |
| 2021 | 362 |
| 2022 | 288 |
| 2023 | 363 |
| 2024 | 352 |

Очікувана кількість календарних днів за 2020–2024 роки — **1827**, тому в наборі відсутні **96 щоденних спостережень**. Найбільше відсутніх дат припадає на 2022 рік.

> **Мій коментар.** NOAA виявився цікавим саме через те, що дані не ідеальні. Тут видно різницю між пропущеним значенням у клітинці та повністю відсутнім спостереженням за певну дату. Для реального аналізу це важливо: відсутній рядок і порожнє значення — не одне й те саме.

### 4.2. NASA POWER Daily

Завантажений CSV містить:

- **1827 записів**;
- **10 полів**;
- повний період `2020–2024`;
- усі календарні дні присутні;
- пропущених значень не виявлено;
- службових значень `-999` у вибірці не виявлено;
- дублікатів комбінації `YEAR + DOY` не виявлено.

Поля:

| Поле | Опис |
|---|---|
| `YEAR` | рік |
| `DOY` | номер дня року |
| `T2M` | середня температура |
| `T2M_MAX` | максимальна температура |
| `T2M_MIN` | мінімальна температура |
| `T2MDEW` | температура точки роси |
| `RH2M` | відносна вологість |
| `PRECTOTCORR` | скориговані опади |
| `WS10M` | швидкість вітру |
| `PS` | поверхневий атмосферний тиск |

> **Мій коментар.** NASA POWER виглядає найзручніше для подальших лабораторних. Тут немає пропущених днів, структура компактна, а всі основні погодні показники вже знаходяться в одній таблиці. Окремого поля `DATE` немає, але комбінація `YEAR + DOY` однозначно визначає дату.

### 4.3. ERA5 Hourly Time-Series

Завантажений CSV містить:

- **43 848 записів**;
- **9 полів**;
- період від `2020-01-01 00:00:00` до `2024-12-31 23:00:00`;
- погодинний крок;
- пропущених значень не виявлено;
- дублікатів `valid_time` не виявлено.

Поля:

| Поле | Опис |
|---|---|
| `valid_time` | дата і час |
| `u10` | U-компонента вітру на 10 м |
| `v10` | V-компонента вітру на 10 м |
| `d2m` | температура точки роси |
| `t2m` | температура на 2 м |
| `sp` | поверхневий тиск |
| `tp` | загальна кількість опадів |
| `latitude` | широта |
| `longitude` | довгота |

> **Мій коментар.** ERA5 має найбільше записів, але це не автоматично робить його найкращим варіантом для цієї роботи. Погодинні дані дають більше деталізації, але водночас ускладнюють роботу в Excel. Наприклад, щоб порівнювати їх із щоденними наборами, пізніше доведеться робити агрегацію за днями.

## 6. Вибір набору для подальшої роботи

Для подальших етапів лабораторної роботи обрано:

## **NASA POWER Daily**

Основні причини вибору:

- набір відповідає тематичному напряму **«Погода»**;
- містить **1827 записів** і **10 полів**;
- охоплює всі календарні дні 2020–2024 років;
- у перевіреній вибірці не виявлено пропущених значень;
- містить основні метеорологічні характеристики: температуру, вологість, опади, вітер і атмосферний тиск;
- має просту табличну структуру;
- формат CSV без проблем відкривається в Excel або Google Sheets;
- розмір набору зручний для наступних лабораторних робіт.

### Коротке обґрунтування для звіту

> Обрано набір даних **NASA POWER Daily**, оскільки він відповідає тематичному напряму «Погода», містить 1827 записів і 10 полів та охоплює повний період 2020–2024 років без пропущених щоденних спостережень. Набір містить основні метеорологічні показники — температуру, вологість, опади, швидкість вітру та атмосферний тиск — і має зручну структуру для подальшого аналізу.

> **Мій коментар.** NOAA теж добре підходить і навіть цікавіший з точки зору проблем якості даних. Але для наступних етапів я обрав NASA POWER, тому що на цьому наборі буде простіше спочатку освоїти самі методи аналізу, не витрачаючи основний час на відновлення великої кількості пропусків. ERA5 залишив як приклад більш деталізованого професійного набору, який за потреби можна буде використати пізніше.
